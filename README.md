# Email Reply Generator

A simple Streamlit web app that creates an email reply using a selected tone.

## Features
- Accepts a received email or message
- Professional, Friendly, and Short reply styles
- Optional custom point to include in the reply
- No paid API key required

## Run locally
1. Install Python 3.10 or later.
2. Open a terminal in this project folder.
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Start the app:
   ```bash
   streamlit run app.py
   ```

## How it works
This starter version uses reply templates. It does not call a GPT API or use a generative AI model.

## Important
Review and edit generated text before sending it.
